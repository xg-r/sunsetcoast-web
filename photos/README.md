# 사진 폴더 (임시 → 원본 교체용)

지금 들어 있는 사진은 **시안용 임시 사진**이다. 현재 sunsetcoast.kr에 공개된 이미지를 긴 변 1,600px로 줄인 것이고,
각 파일의 원래 주소는 `index.json`의 `source`에 적혀 있다. 원본으로 바꿀 때는 **같은 폴더에 같은 규칙의 이름으로 넣으면 된다.**

## 파일명 규칙

```
photos/rooms/{객실 slug}/{카테고리}-{번호 2자리}.jpg
photos/site/{묶음}/{이름}-{번호 2자리}.jpg
```

- 소문자 영문, 하이픈(-)만 사용. 한글·공백 금지.
- 번호는 `01`부터, 갤러리에 나오는 순서. 사진을 빼면 번호는 다시 매기지 않아도 된다 (빈 번호는 건너뜀).
- 확장자는 `.jpg` `.jpeg` `.png` `.heic` 아무거나 괜찮다. 빌드할 때 WebP/AVIF로 바꾼다.

| 객실 | slug | 객실 | slug |
|---|---|---|---|
| 놀멍 | `nolmeong` | 태산이 | `taesani` |
| 물멍 | `mulmeong` | 춘삼이 | `chunsami` |
| 쉬멍 | `swimeong` | 바다 | `bada` |
| 불멍 | `bulmeong` | 노을 | `noeul` |
| 수애기 | `suaegi` | 고래 | `gorae` |
| 곰새기 | `gomsaegi` | 해안 | `haean` |
| 제돌이 | `jedori` | 바람 | `baram` |

### 객실 사진 카테고리

| 파일명 | 화면 이름 | 규칙 |
|---|---|---|
| `cover` | 대표 | 객실당 1장 (`cover-01`). 해 질 녘 사진 권장 |
| `exterior` | 외관 | |
| `bedroom` | 침실 | 거실·식탁 등 실내 전체도 여기에 |
| `bath` | 욕실 | **필수.** 없으면 상세 화면에 "욕실 사진 준비 중"이 나온다 |
| `kitchen` | 주방 | |
| `deck` | 데크 | 바베큐 데크, 야외 스파 |
| `view` | 전망 | 객실에서 보이는 바다·노을 |
| `pet` | 반려견 | 반려견 동반 객실만 |

예: `photos/rooms/jedori/bath-01.jpg` → 제돌이 욕실 탭의 첫 번째 사진.

### 사이트 공통 사진 (`photos/site/`)

| 폴더 | 이름 | 쓰는 곳 |
|---|---|---|
| `hero` | `hero-01` … | 홈 대표 이미지 (01이 기본) |
| `dolphin` | `dolphin-01` … | 돌고래 이야기, 돌고래 소식 |
| `night` | `night-01` … | 밤 분위기, 인스타그램 영역 |
| `tier` | `premium-01` `airstream-01` `value-01` | 홈의 등급 카드 |
| `facility` | `bbq-01` `bike-01` `mealkit-01` `shower-01` `laundry-01` `kitchen-01` `shelter-01` … | 시설과 서비스 |

## 지금 상태 (임시 사진 기준)

- 현재 사이트가 놀멍·물멍·쉬멍을 한 페이지, 에어스트림 5동을 한 페이지로 보여줘서, 사진도 묶음 단위로만 있다.
  그래서 대표 객실(놀멍, 수애기)에만 전체 사진을 넣고, **물멍 · 쉬멍 · 곰새기 · 제돌이 · 태산이 · 춘삼이는 대표 사진 1장만** 넣었다.
  이 6동은 욕실 사진이 없어 "욕실 사진 준비 중"으로 나온다.
- 나머지 8동(놀멍, 불멍, 수애기, 바다, 노을, 고래, 해안, 바람)은 현재 사이트에 욕실 사진이 있다.
- 반려견(`pet`) 사진은 아직 없다.
- 브롬톤 자전거, 밀키트, 공용시설 사진은 현재 사이트에서 찾지 못했다.

## 만드는 방법

`design/_tools/manifest.json`에 원본 사진과 대상 파일의 매핑이 있고, `design/_tools`에서 `node build-temp-photos.mjs`를 실행하면 다시 생성된다.
원본 사진을 직접 넣게 되면 이 스크립트는 더 쓰지 않는다.
